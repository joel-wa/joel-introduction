# Headwind showcase artwork

`headwind-cover.jpg` is an editorial illustration generated with the built-in ImageGen tool, using an actual Headwind game screenshot as its reference. It is not a gameplay screenshot and is labelled accordingly on the website. The artwork was exported to JPEG for the web; its composition was not changed.

The reference was captured from https://joel-wa.github.io/headwind/ with the camera off. No personal camera image was used.

## Final generation prompt

Use case: stylized-concept. Asset type: a single landscape project-cover illustration for Joel's personal portfolio website, not an asset used inside the game UI. Input image 1 is a reference screenshot of Joel's actual HEADWIND browser game. Create a restrained, beautifully composed editorial illustration based closely on the simple flat game: the same tiny round yellow bird with orange triangular beak, single large white-and-black eye and small golden wing, facing right, in a pale sky blue environment with soft white oval clouds and gentle mint-green hills along the bottom. Show two simple mint/forest-green paired pipe obstacles with wide openings, recognizable flying-game gameplay. Flat clean shapes with exceptionally subtle paper texture and refined muted colors to suit a Japanese-inspired cream, forest-green, and vermilion portfolio. Landscape 3:2 composition, bird at left center, pipe opening toward right center, generous sky around it; balanced and easy to recognize at small size. Slight depth from overlapping paper-like shapes only; do not turn into elaborate 3D. Keep it honest to the screenshot's friendly simple geometry, not a fantasy reimagining. Remove all HUD, score, camera boxes, overlays, browser chrome, labels, and text. No text anywhere, no person, no webcam image, no badges, no fake app interface, no neon, no glow, no visual clutter, no dramatic scenery. This is artwork inspired by a real game, not a screenshot; it must feel understated, warm, and polished.
